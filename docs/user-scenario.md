# 대표 사용자 시나리오

인포그래픽과 기획안의 작동 방식을 설명하기 위한 **가상 예시**입니다. 실제 사용자 테스트나 효과 검증 결과가 아닙니다.

## 상황

한국인 학생 3명과 중국인 유학생 1명이 글로벌비즈니스 발표에서 해외 기업을 비교하려 합니다. 대화의 주제와 비교 기준이 빠르게 바뀌고, 이후 자료 조사 업무로 이어지는 상황입니다.

## 1. 대화에서 주제와 질문이 등장

> A: 우리 발표에 미국 기업 사례를 넣으면 어떨까?
>
> B: 중국 기업이랑 비교해도 재밌겠다.
>
> C: 그럼 중국에서는 어떤 기업을 조사하지?
>
> A: 비교 기준도 정해야 할 것 같아.

현재 제안은 미국·중국 기업 비교입니다. 구체적인 중국 기업과 비교 기준은 아직 결정되지 않았습니다.

## 2. 공통 토론 흐름 카드

| 항목 | 카드 내용 |
| --- | --- |
| 현재 주제 | 해외 기업 사례 선정 |
| 주요 의견 | 미국 기업과 중국 기업 비교 |
| Q01 | 중국에서는 어떤 기업을 조사할 것인가? |
| Q02 | 두 기업을 어떤 기준으로 비교할 것인가? |
| 상태 | 검토 중 |
| 근거 | 위 대화의 실제 메시지 ID와 원문 |

## 3. 설정에 따른 비공개 안내

새로운 질문이 등록되면 안내를 허용한 사용자에게 다음과 같이 표시합니다.

> 해외 기업 사례에 관한 새로운 질문이 등록되었습니다. 현재 논의를 확인하거나 의견을 작성하시겠어요?

사용자는 맥락 확인·의견 작성·건너뛰기 중 원하는 행동을 선택합니다. 특정 학생을 저참여자로 분류해 알리는 방식은 사용하지 않는 설계입니다.

## 4. 개인 공간에서 의견 준비

학생은 Q01을 선택하고 중국어로 설명을 확인합니다. 개인 AI와 추가 질문을 나누며 다음 의견을 작성할 수 있습니다.

> 중국의 BYD와 미국의 Tesla를 비교하면 좋겠습니다.

AI는 번역문을 미리 보여주고 학생이 수정할 수 있도록 합니다. 본인이 공유를 승인하면 팀 채팅에 의견이 게시되고 Q01에 연결됩니다. 개인 질문과 초안은 개인 공간에 남습니다.

## 5. 질문 검토와 팀의 결정

팀은 기업과 비교 기준을 검토한 뒤 다음 내용을 확인했다고 가정합니다.

- Q01: BYD와 Tesla를 비교한다.
- Q02: 같은 기준 연도와 자료 범위에서 매출·시장점유율을 비교한다.

팀원이 결정 내용을 확인하고 질문을 ‘해결됨’으로 변경합니다. 새 분석이 아니라 사람의 확인이 결정 기록의 근거가 됩니다.

## 6. 모호한 업무 요청을 조건으로 정리

> 중국 기업 쪽 자료 조사해서 Tesla랑 비교할 수 있게 정리해 줘.

AI는 이전 결정과 연결해 업무 카드 초안을 제안합니다.

| 항목 | 초기 초안 |
| --- | --- |
| 업무명 | 중국 전기차 기업 자료 조사 |
| 목적 | BYD와 Tesla 비교를 위한 자료 준비 |
| 관련 결정 | Q01 기업 선정, Q02 비교 기준 |
| 조사 범위 | BYD, 같은 연도·범위의 매출과 시장점유율 |
| 담당자 | 확인 필요 |
| 결과물 형식 | 확인 필요 |
| 기한 | 확인 필요 |

팀은 담당자와 발표용 비교표·참고 자료, 제출 기한 등을 확인해 카드를 확정합니다. 담당자는 자신의 언어로 요구사항을 읽고 모호한 부분을 다시 질문할 수 있습니다.

## 7. 작업·제출·검토

담당 학생이 상태를 ‘진행 중’으로 바꾸고 자료를 조사합니다. 문서·비교표 링크를 등록한 뒤 ‘검토 요청’으로 변경합니다. 팀은 이전에 확인한 조사 기준과 제출 자료를 함께 보며 수정할 내용을 전달합니다.

최종 자료의 검토와 반영을 확인한 뒤 업무를 완료로 기록합니다. 파일 확장자나 내용이 있다고 해서 AI가 자동으로 품질 검토를 마친 것으로 처리하지 않습니다.

## 8. Contribution 기록

| 항목 | 기록 예시 |
| --- | --- |
| 담당 업무 | BYD 자료 조사와 기업 비교 |
| 등록 결과물 | 조사 문서, 비교표 링크 |
| 검토 상태 | 팀 확인 완료 |
| 반영 내역 | 해외 기업 비교 슬라이드와 핵심 지표 표에 활용 |
| 연결 근거 | 업무 카드, 제출 링크, 팀의 검토·반영 기록 |

이 기록은 의견이 어떻게 업무가 되고 공동 결과물에 쓰였는지 확인하기 위한 것입니다. 개인의 전체 기여도를 계산한 성적이나 순위로 해석하지 않습니다.
