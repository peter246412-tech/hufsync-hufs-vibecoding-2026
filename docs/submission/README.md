# 공개 자료 안내

## 기획서 공개본

[HUFSync 기획서 PDF 공개본](hufsync-proposal-public.pdf)

사용자가 제공한 2026년 11월 10일자 참가 신청서·아이디어 기획서에서 포트폴리오 공개에 필요한 본문을 보존한 자료입니다.

- 원문 16쪽 중 기획 본문이 있는 1~14쪽을 포함했습니다.
- 1쪽의 신청자 개인정보 표와 상단 신청서 정보는 실제 PDF 텍스트·이미지 객체를 제거하고 공개본 제목으로 대체했습니다.
- 15~16쪽의 개인정보·참가자 동의서는 제외했습니다.
- 첫 쪽의 기획 배경과 이후 본문은 유지했습니다.
- 학번·연락처·이메일·동의서가 추출 텍스트에 남지 않는지 확인했습니다.

개인정보가 포함된 원본 신청서와 이전 DOCX 원본은 이 저장소에 올리지 않았습니다. 읽기 쉽게 재구성한 내용은 [기획안 정리](../proposal.md)에서 확인할 수 있습니다.

## 시스템 인포그래픽

[HUFSync 전체 시스템 아키텍처 인포그래픽](../assets/hufsync-system-architecture.png)

사용자가 제공한 PNG를 변경 없이 복사했습니다. 기획 기능과 협업 흐름을 설명하는 자료이며 구현 완료를 뜻하지 않습니다. 인포그래픽과 본문에 나오는 Q01·Q02는 질문 연결을 설명하는 상황별 예시 ID입니다.

## 문서의 기준

- 최신 기획안과 인포그래픽을 현재 설계의 기준으로 삼았습니다.
- 이전 검토의 점수·가중치·지니계수는 [설계 변화](../design-evolution.md)에 배경으로 구분했습니다.
- 교수 피드백은 설계 판단과 연결한 요지로 정리했으며 이메일 캡처는 공개하지 않았습니다.
- 가상 사용자 시나리오, 계획한 테스트, 실제 수행 결과를 구분합니다.
- 참고 논문은 출처 링크로 연결하고 전문을 다시 업로드하지 않았습니다.
